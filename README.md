# 🎬 B站视频转录助手

一个简洁优雅的B站视频转录和总结工具,将视频内容转换为文字并生成智能总结。

## ✨ 功能特性

- 📺 **视频链接输入** - 支持 bilibili.com 和 b23.tv 短链接
- 🎬 **视频信息展示** - 自动获取视频标题、UP主、封面和时长
- 📊 **实时进度显示** - 4步骤进度指示器(解析→提取→识别→总结)
- 📝 **文本转录** - 将视频语音转写为中文文字
- 📄 **智能总结** - AI生成的视频内容摘要
- 📋 **一键复制** - 快速复制转录和总结内容
- 💾 **多格式导出** - 支持 TXT、Markdown 和 JSON 格式
- 📱 **响应式设计** - 完美适配桌面和移动设备

## 💻 技术栈

### 前端 (已实现)
- HTML5
- CSS3 (渐变、动画、Flexbox/Grid)
- Vanilla JavaScript (ES6+)
- 响应式设计

### 后端 (待开发)
- **推荐**: Python + FastAPI
- **视频下载**: you-get / yt-dlp
- **音频处理**: FFmpeg
- **语音识别**: OpenAI Whisper / 阿里云 / 腾讯云
- **文本总结**: OpenAI GPT-3.5/4

## 📚 使用说明

1. **输入链接**: 在输入框中粘贴B站视频链接
2. **开始处理**: 点击"开始处理"按钮
3. **查看结果**: 观看实时进度,阅读转录文本,查看智能总结
4. **导出或复制**: 使用复制按钮或选择格式导出文件
